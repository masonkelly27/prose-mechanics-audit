# Show-vs-Tell Audit Reference

Pure session judgment — flags significant emotional/internal beats that
are named rather than dramatized.

## What This Catches
"She was furious" at a scene's emotional climax, where dramatization
(action, sensation, dialogue) would land harder.

## What This Does NOT Catch
Correctly summarized emotion at minor beats — telling is often the right
pacing choice, and flagging every instance would be noise, not signal.

## How to Run

Perform this audit by reading the text directly. Apply the same judgment directly while reading.
